## §0 本项目与 NCM 版的差异登记（v6，必读）

PolyXRD-NCA 以 PolyXRD-NCM v0.1.0 为骨架移植（同构：两者都是 R-3m #166
层状锂过渡金属氧化物，差别只在 3b 位是 **Al** 还是 **Mn**）。移植时**判据
阈值一个没动**，改的是"数据面"：CIF 库、候选池、样本库、真实锚点。因此
阅读本文件与 `docs/VALIDATION*.md` 时必须先分清三类数字：

| 类别 | 含义 | 是否可照搬到 NCA |
|---|---|---|
| **判据/阈值** | §1–§5 的所有常量 | ✅ 完全一致，NCM 版实测全部保留 |
| **NCM 版实测锚点** | Rwp=3.0409 / occ=0.98689 / D=153.4 nm 等 | ⚠️ 那是 **NCM811 模型** 给出的数，不能当 NCA 的基准 |
| **NCA 版实测锚点** | 本文与 `VALIDATION*.md` 标注 **v6** 的条目 | ✅ 本环境的 NCA 基准 |

**最要紧的一条口径**：家族数据根（`D:/Project/XRD/XRData/`）里**没有
NCA 实测谱**。唯一可用的三元层状正极实样是 NCM811（`Data040`），它被
当作**同构锚点**使用。用它 + NCA 模型精修，代价是可量化的：

| 量 | NCM 模型（原始口径） | NCA 模型（本期口径） | 说明 |
|---|---|---|---|
| stage1 Rwp | 3.0409 % | **3.1607 %** | 化学错配 +0.12 pp |
| a / c | 2.87185 / 14.19502 | **2.87185 / 14.19502** | 晶胞逐位不变 |
| 全管线 Rwp | 3.1151 % | **3.7452 %** | stage2/3 阶段差异放大 |
| 晶粒尺寸 D | 155.0 nm | **104.8 nm（仅尺寸）/ 143.0 nm（尺寸+应变）** | 落不同盆地，见 VALIDATION_TCH §7 |

## §1 物相判定门（三重判据）

初版策略：**只挡明显非层状相**，稳妥优先。宁可放过可疑样品，也不误拦正确数据。

| 判据 | 指标 | 阈值 | 唯一出处 |
|---|---|---|---|
| **C1** 峰位序列匹配 | 前 12 强峰与 R-3m 理论峰的 2θ 均方根偏差 | **RMS ≤ 0.10°** | `C1_RMS_MAX` |
| **C2** 特征分裂 | (006)/(012)≈38° 与 (108)/(110)≈64.5° 的双峰可分辨 | **Δ2θ ≥ 0.10°** | `C2_SPLIT_MIN` |
| **C3** 峰强比 | I(003)/I(104) | **0.5 ≤ R ≤ 3.0** | `C3_RATIO_MIN/MAX` |

**阈值依据**：实测同构锚点 NCM811（XRData/csuHJW/Data040，用 NCA_80_15_05
模型）用文献晶胞未精修即命中 11 个主峰、偏差 ≤0.03°；C1 阈值取 3 倍余量。
C3 覆盖层状 NCA 典型 1.1–1.6，同时放过混排较重的样品（混排程度由精修输出，
不在此处卡）。

**杂质容忍**：允许存在强度 ≤ 最强峰 10% 的未知弱峰（`C_IMPUIITY_TOL`）。
实测该样品在 24.58°（d≈3.62 Å，约 2.6%）即存在一个非 R-3m 弱峰。

**前驱体分流**（独立子门，不参与 C1–C3）：
| 结构类型 | 空间群 | 结论 |
|---|---|---|
| 三元氢氧化物（类 β-Ni(OH)₂） | P-3m1 | `precursor_hydroxide` |
| 三元碳酸盐（方解石型） | R-3c | `precursor_carbonate` |
| 层状氧化物 | R-3m | 走 C1–C3 |
| 其余 | — | `other`（拦下） |

**边界声明（必须写入界面措辞）**：判定门只保证"是层状 R-3m 锂过渡金属氧化物
结构类型"。NCA 四档配比（80:15 / 82:13 / 85:10 / 90:05）/ NCM / LiNiO₂ 的晶胞
几乎相同（a 差 <0.01 Å），实验室 XRD **分不开**；Ni:Co:Al（或 NCM 的
Ni:Co:Mn）具体比例需 ICP/EDS 确定。可区分的是 LCO（a≈2.814，差 1.9%）、
尖晶石（Fd-3m）、橄榄石（Pnma）。

## §2 R 因子口径

| 因子 | 定义 | 口径 |
|---|---|---|
| Rwp | `100·√(Σw(y_o−y_c)² / Σw·y_o²)` | **背景计入全点**（GSAS-II 口径） |
| Rp | `100·Σ\|y_o−y_c\| / Σy_o` | 同上 |
| Rexp | `100·√((N−P)/Σw·y_o²)` | 同上 |
| GOF | `Rwp / Rexp`（= √χ²） | 同上 |
| **RB** | `100·Σ\|I_obs−I_calc\| / Σ I_obs`（逐峰积分强度） | 扣背景；重叠区按**计算贡献**分配（见下） |

**RB 的分配口径（T4.1 冻结）**：数据点按"各峰模型形状 × 计算权重"归一化归属，
`frac_p(x) = w_p·s_p(x) / Σ_q w_q·s_q(x)`（s_p 为单位面积伪 Voigt，w_p = |F|²·LP
含 PO 权重）；实测与计算用**同一套归属权重**积分，故重叠区不重复计数。
归属权重取自模型形状 ⇒ 实测峰位偏移会造成该峰实测积分不足，RB 对峰位与
强度误差都敏感。与 GSAS-II 的差别仅在重叠峰分配细节（hkl 级 vs 合并峰级），
GSAS-II 装好后（T8）做交叉比对。

**RB 与 Rwp 的关系（不要互相替代）**：Rwp 逐点比较且被大量背景点稀释；
RB 比较峰积分强度，对局部模型失配（如 (006)/(012) 区）更敏感。**NCA 口径实测**
（v6，同构锚点 Data040 + NCA_80_15_05 模型）：Rwp = **3.1607 %** 而
RB = **4.9915 %** —— RB 比 Rwp 高 1.8 pp，仍是因为 38° 区模型高估（NCM 版
同现象：3.04 % / 4.65 %）。**报告须同时给出两者**，不可只报 Rwp。

权重：`w = 1/σ²`，σ 缺省 `√max(y_obs, 1)`（计数统计，`RFACTOR_SIGMA_FLOOR=1.0`）。

**注意（写入界面提示）**：强计数数据的 Rexp 很低（实测 1.42%），GOF 会显得偏大
（实测 5.55）而 Rwp 仅 7.87%。判据以 **Rwp 为主、GOF 为辅**，并同时显示 Rexp。

## §3 尺寸-应变峰形（TCH 伪 Voigt）

高斯项（Caglioti）：`FWHM_G² = U·tan²θ + V·tanθ + W`
洛伦兹项（尺寸 + 应变）：`FWHM_L = X·tanθ + Y/cosθ`

- 尺寸项由 **Y** 承载：`Y = (180/π)·Kλ/D`（**度**，与 θ 无关的常数；角度
  依赖全部由 `1/cosθ` 因子承载）→ `D = (180/π)·K·λ/Y`，`K = 0.89`（球形，
  体积加权）。
  > **v2 修正**：v1 此处误写为 `Y = Kλ/(D·cosθ)` / `D = Kλ/(Y·cosθ)` ——
  > cosθ 已在 `FWHM_L = Y/cosθ` 中出现一次，Y 本身是 2θ 尺度的常数系数，
  > 不得再除 cosθ。实现以 `size_strain.py` 为准。
- 应变项由 **X** 承载：`X = (180/π)·4ε`（度，常数）→ `ε = (π/180)·X/4`。
- 合成：`FWHM = (FWHM_G⁵ + 2.69269·FWHM_G⁴·FWHM_L + 2.42843·FWHM_G³·FWHM_L²
  + 4.47163·FWHM_G²·FWHM_L³ + 0.07842·FWHM_G·FWHM_L⁴ + FWHM_L⁵)^(1/5)`
- η 由 TCH 公式给出（替代固定 eta 参数）。

**为什么必须加这一项**：实测基线拟合中 Caglioti `U` 收敛到 0、经验衰减 `B=3.32`
（物理合理值应 <0.5），说明模型缺少尺寸/应变宽化，被迫用高角强度衰减去补偿。

**术语口径（写入界面）**：XRD 给出的"晶粒尺寸"是**相干衍射畴尺寸**（volume-weighted
column length），不是 SEM 观察到的二次颗粒粒径。D > 5 μm 时 `Kλ/D < ~1e-5°`，
低于常规实验室谱拟合精度 —— 统一报"超出检出上限"（`crystallite.D_DETECT_MAX_NM`）。

## §4 占位与坐标精修边界

| 参数 | 边界 | 约束 |
|---|---|---|
| `occ_Li3a`（3a 位 Li 占有率） | `[0.5, 1.0]` | `occ_Li3a + occ_Ni3a = 1`（Li/Ni 混排守恒） |
| `z_O`（6c 位 O 的 z 坐标） | `[0.20, 0.28]` | — |
| 3b 位 TM 比例 | 默认**固定**为 CIF 值 | 由 ICP 名义配比决定，不由 XRD 精修 |

**可辨识性说明（关键）**：Li 散射因子极低，`occ_Li3a` 与整体 B 因子、择优取向、
标度**强相关**。单相 XRD 的绝对值精度通常只有 **±0.02–0.03**，适合做**同批次样品
间的相对比较**，不适合当绝对真值。因此精修后**必须**输出参数相关性矩阵，界面在
Li 占位旁标注精度与相关系数。

## §1 附：v3 细化（T5.1 实施后的实测口径）

### (1) C1 的「理论峰」是标定后的

CIF 自带晶胞是**文献值**，与实测差 0.2–0.3%（实测 a=2.87185 vs CIF 2.86450），
而 2θ 偏差随 tanθ 放大：

| 2θ | 18.8° | 44.5° | 77° |
|---|---|---|---|
| 偏差 | −0.04° | −0.10° | −0.23° |

直接拿 CIF 晶胞比，C1 的 RMS 实测 **0.164°，恒超 0.10° 阈值** —— 判定门形同
虚设（初版探测脚本实测）。因此判定门先做一次**快速晶胞标定**：

```
匹配 → LM 拟合 (a, c) → 重匹配（3 轮，`CALIB_ROUNDS`）
```

标定后 RMS **0.164° → 0.0138°**，标定得 a=2.87158 / c=14.19411，与 40 秒
全谱精修锚点 (2.87185 / 14.19502) 相差 **0.01%**。

标定检验的是**结构类型**（层状 R-3m 的峰位序列特征），不检验晶胞绝对值 ——
这正是 §1 边界声明要表达的：NCA 各配比 / NCM / LiNiO₂ 的晶胞几乎相同，实验室
XRD 分不开，Ni:Co:Al 比例须由 ICP/EDS 确定。

**标定只拟合 (a, c)**：三角/六方晶系 a=b、γ=120° 恒定；正交/立方体系不做
标定（判定门范围只覆盖层状 NCA 及其前驱体）。

### (2) 结构可信度三门槛（分流阶段）

晶胞快速标定只有 2 个自由度 —— **什么谱都能拟合出一个像样的峰位 RMS**。
只按 RMS 挑最佳候选会翻车（T5.1 实测缺陷，已修）：

| 样品 | 只看 RMS 的旧口径 | v3 修正后 |
|---|---|---|
| 岩盐 NiO | 判成 `precursor_carbonate`（RMS 0.069°） | `other` |
| 尖晶石 LiMn₂O₄ | 判成 `nca` | `other` |
| 金红石 TiO₂ | 判成 `nca`（RMS 0.079°） | `other` |
| 纯噪声谱 | 判成 `precursor_hydroxide` | `other` |

三道门槛（缺一不可）：

| # | 门槛 | 阈值 | 常量 |
|---|---|---|---|
| 1 | **峰位**：命中峰数 ≥ 6 且 RMS ≤ 0.10° | — | `C1_MIN_MATCH` / `C1_RMS_MAX` |
| 2 | **晶胞**：标定后相对原 CIF 晶胞偏差 | ≤ 3% | `CALIB_CELL_TOL_PCT` |
| 3 | **强度指纹**：标定后理论谱 vs 实测谱 Pearson 相关 | ≥ 0.85 | `C_FINGERPRINT_MIN` |

第 2 道专治「标定把尖晶石的 a=8.25 Å 拉到 2.80 Å」这类强行拟合；第 3 道
要求**强度分布**也一致 —— 实测真结构 0.92–0.98，非结构 −0.02–0.55，判别
裕度充足。

> 峰位**逐峰**强度相关不可用：实测 LiCoO₂ 仅 8 个峰匹配，逐峰相关也有 0.997
> （假高）。故指纹相关必须用**整谱**曲线。

### (3) 结论语义

- `ok=True` ⇔ kind=`nca` 且 C1–C3 全过 → 可进入 NCA 精修。
- `kind` 是**结构类型**，`ok=False` 时同样给出。例如 LiCoO₂ 是层状 R-3m，
  `kind=nca` 而 `ok=False`（晶胞非标准 NCA）→ 界面措辞「疑似层状氧化物但晶胞
  不符，是否仍按 NCA 精修？」而不是硬拒。

### (4) 判定门内部预处理（不可省略）

判定门**必须**剥离 Kα2：Cu Kα2 相对 Kα1 的位移在 44° 处已达 0.11°，与 C1 的
RMS 阈值同量级。不剥离会把 Kα2 伴峰误配成主峰（实测贪心匹配选中 Kα2 峰，
RMS 0.09°→0.13°，假偏差）。

| 峰数 | 判读 | 常量 |
|---|---|---|
| < 6 | 不是可用的 XRD 粉末谱 | `C1_MIN_MATCH` |
| > 60 | 含大量噪声（纯噪声谱实测 694 峰） | `C_MAX_OBS_PEAKS` |

## §1 附二：v4 细化（T5.2 实施后的实测口径）

### (5) C1 改「先匹配、后取强」

原实现是「实测前 12 强」与「理论前 12 强」**按序硬配**。但这两套是**独立的
强度排序**，对不同配比的层状氧化物并不一致 —— NCA_80_15_05（Ni 80 % / Co 15 % /
Al 5 %）与 LiNiO₂（Ni 100 %）峰强分布不同，按序硬配会漏掉一半：实测 LiNiO₂
合成谱因此只命中 5 个主峰而被漏检。

v4 口径：**先把理论峰与实测峰全量贪心匹配，再在匹配上的对里取实测强度前
N 强算 RMS**。命中数门槛（`C1_MIN_MATCH`）作用于总配对数。

### (6) 标定：池中最佳 + 迭代剔除离群配对

标定对**初值敏感**：文献晶胞差 0.4% 就可能把匹配带偏并收敛到错误的 (a, c) ——
实测 LiNiO₂ 谱用 NCA_80_15_05 参考标定得 a=2.861（真值 2.8755），因为 44.4° 的真峰
被配到 44.62° 的理论峰，LM 随即被拉偏；改用 NCA_82_13_05 标定得 a=2.876（正确）。

v4 口径两项加固：
1. **迭代剔除离群配对**：每次拟合后剔除偏差 > 3×RMS 的配对并重拟合（≤3 轮）；
2. **池中最佳标定**：对候选池逐个标定，取 RMS 最小者作为最终参考（初值覆盖
   多个晶胞，绕开单一起点的局部最优）。判定门先走「只用内置参考」的快速
   路径，全过即收工；否则才做池中全标定。

### (7) NCA 族 a 判据（层状类型 ≠ NCA 成品）

C1–C3 只判**结构类型**（层状 R-3m），不判**型号**。但 §1 边界声明指出 LCO
可区分（a≈2.814，差 1.9%）—— 若不设防，LiCoO₂ 谱会被当作 NCA 放行
（T5.2 实测：修正标定后 LCO 确实 C1–C3 全过、ok=True → **误纳**）。

| 项 | 值 | 常量 |
|---|---|---|
| NCA 族标定 a 区间 | 2.818 – 2.890 Å | `NCA_FAMILY_A_RANGE` |

依据（内置 CIF 晶胞，v6 实测）：NCA_80_15_05 / NCA_82_13_05 / NCA_85_10_05 /
NCA_90_05_05 四档同为 **2.8645**（共用同一骨架，见 §0）/ LiNiO₂ 2.8755 /
NCA_delith（脱锂层状）2.8220；界外最近的是 LiCoO₂ **2.8140**。

- 下限 2.818：LiCoO₂ 实测标定 a=2.8142（低 0.0038 Å，标定精度约 0.0003 Å，
  裕度 >10 倍）；脱锂 NCA 2.8220 仍在窗内。
- 上限 2.890：覆盖 LiNiO₂ 与 NCA（NCA a≈2.88）。
- **必须防的假阳性**：γ-LiAlO₂ 的**高压 R-3m 变体**（COD 9009880，a=2.8003）
  同为 #166，只靠空间群会把铝偏析相当成正极 —— a 判据把它挡在窗外，且它
  在实际样品里以四方 P4₁2₁2（a=5.1965）形式存在，由 `al_phase` 分支指认。

**越界时的行为**：`ok=False`、`kind` 仍为 `nca`（层状结构类型保留），理由写明
「疑似 LiCoO₂ 等其他层状氧化物，或脱锂体系；不按 NCA 成品放行」。

### (8) 已知局限

- **前驱体分流依赖 CIF 多型匹配**：真实 β-Ni(OH)₂（a≈2.68 Å）与池内 COD
  1548811（a=3.127 Å）不是同一多型，晶胞偏差门槛（3%）会拦下，分流为
  `other` 而非 `precursor_hydroxide`。要覆盖更多前驱体多型，需扩充候选池。
  （v6：NCA 版池内新增 `precursor_NCA_OH`（P-3m1，a=3.1268 / c=4.6060），
  实测真实三元氢氧化物前驱体 Data043 已能正确分流 —— 本条局限只对**其他
  多型**成立。）
- **NCA 配比不可分**：四档 NCA / NCM / LiNiO₂ 晶胞几乎相同，峰强差
  0.03–0.14 %（`tests/test_real_models.py::test_model_intensity_differences_are_sub_percent`
  实测），判定门不区分，须由 ICP/EDS 定 Ni:Co:Al。

## §1 附三：v5 细化（T8.2 实施后的实测口径）

真实数据验证（`XRData/csuHJW/Data043`，(Ni,Co,Mn)(OH)₂ 前驱体实样）抓出
两处**判定门内部**的模型失配。两处都**不动任何判据阈值**，只修实现。

### (9) 寻峰要带突出度门槛（`PEAK_PROMINENCE_FRAC`）

- **缺陷**：`peaks.find_peaks` 原用 `prominence=0`，只按「峰高 ≥ 1 % × 最强
  峰高」过滤。低强度实样上噪声肩会被算成峰。
- **实测**：Data043 最强峰 3389 计数、噪声肩 2–4 % 相对强度 → 寻得
  **62 个峰**，超过 `C_MAX_OBS_PEAKS = 60` → 判定门在「噪声」分支直接返回
  `other`，理由写"谱图含大量噪声"。而该谱真实峰只有 **9 个**。
- **修**：`prominence ≥ 1 % × 最强峰高`。同谱 62 → 9 峰；T5.2 全部 22 个
  样本的 ok/kind **逐个不变**（真实 Bragg 峰的突出度等于自身高度，远高于
  1 %，门槛只砍噪声肩）。
- **否决的方案**：「按分辨率合并邻近峰」。合并 0.12° 会把 (006)/(012) 与
  (108)/(110) 双峰并掉 —— C2 判据正是判这两对双峰，合并等于废掉 C2；
  实测 5 个 NCA 正样本立刻漏检。

### (10) 指纹相关的理论峰宽必须由实测谱反演

- **缺陷**：`_fingerprint_corr` 把理论谱峰宽写死 `U=0.03/V=−0.01/W=0.008`
  （半高宽 ≈0.1°），与实测峰宽无关。峰宽失配会把整谱 Pearson 相关严重压低。
- **实测**：Data043 峰宽 ≈0.35° → corr **0.711 < 0.85**，分流阶段判定
  "没有任何结构能可信匹配" → `other`。按实测峰宽反演后 corr **0.965**。
- **修**：新建 `nca/core/fingerprint.py`：测强峰 FWHM（半高基线取峰两侧
  ±`FINGERPRINT_FWHM_WIN_DEG` 内最小值）→ 固定 U=0 用 `(tanθ, 1)` 最小二乘
  解 (V, W)（若 Γ² 在区间内非正则退化为定宽）。
- **阈值 `C_FINGERPRINT_MIN = 0.85` 保持不变**；区分度反而更宽：
  | 候选结构 | corr（写死峰宽） | corr（反演峰宽） |
  |---|---|---|
  | precursor_NCA_OH / precursor_NiOH2 | 0.711 | **0.965** |
  | NCA_80_15_05 / NCA_82_13_05 / NCA_85_10_05（错配） | 0.200 | 0.000–0.200 量级 |
  | precursor_NCA_CO3 / precursor_NiCO3（错配） | 0.191 | 0.190 量级 |
- **(8) 的更正与保留**：(8) 原把「真实前驱体被判 other」归因于**多型不匹配**
  （a≈2.68 Å 的另一多型）。实测表明 Data043（a=3.13 Å，与池内 CIF 同多型）
  被判 other 的**真实原因是指纹峰宽写死**，已修；而 (8) 描述的"另一多型
  仍会被 3 % 晶胞偏差门槛拦下"这一局限**依然成立**，要覆盖更多前驱体多型
  仍须扩充候选池。

### (11) 双候选择优的边界解让位（`TCH_BOUNDARY_TIE_TOL`）

不属于判定门，但同属"按数值择优会选错"的同类问题，一并冻结口径：

- `pipeline._run_stage1b` 用两个初值各跑一次 LM，按加权 Rwp 取优（v2 起的
  口径）。实测合成 NCA_82_13_05（真值 Y=0.06043 / D=130 nm）：
  谷扫描候选 Y=0.06058、Rwp 12.294 %；普通候选 **Y=0（D=inf）**、
  Rwp **12.190 %** —— 只差 0.85 %，按 Rwp 会选边界解，把 130 nm 报成
  "超出检出上限"。
- **口径**：胜出者 Y 停在下界且另有内部解其 Rwp ≤ 胜出者 ×(1+5 %) 时
  **取内部解**；其余情形与纯 Rwp 取优逐位一致。
- **依据**：「拟合同样好时优先非边界解」是优化与 Rietveld 的通行做法，
  边界解先验可信度更低；5 % 容差与 Rwp 的实验重现性同量级。
- **端到端验证**：同一合成谱加上述规则后 D = **129.7 nm**（真值 130，
  误差 0.23 %），Rwp 10.607 %（比边界解的 10.511 % 略高 0.9 % —— 这是
  取内部解的代价，属预期而非退化）。同构锚点的 NCA 口径复现值见 §0 表
  （Rwp 3.7452 / D 104.8 / occ 0.9869；NCM 模型下为 3.1151 / 155.0 / 0.98689）。
